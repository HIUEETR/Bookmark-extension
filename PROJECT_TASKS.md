# My Bookmark 项目改进与新功能任务表

> 基于当前代码结构（React + Vite + Chrome Manifest V3 书签扩展）整理。优先级说明：P0 = 明确影响现有功能；P1 = 明显提升稳定性/体验；P2 = 可规划的新功能或工程增强。

## 改进任务

| ID      | 优先级 | 类型       | 任务                                                 | 现状/问题                                                                                                                                                       | 建议方向                                                                                                 | 验收标准                                                                                |
| ------- | ------ | ---------- | ---------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| IMP-001 | P0     | Bug 修复   | 修复书签导入逻辑                                     | `src/App.tsx` 中 `handleImport` 解析了上传文件 `data`，但实际导入时优先读取当前浏览器书签树并把现有书签再次导入，可能导致重复导入且没有使用上传文件内容。 | 明确导入格式；校验 JSON 后从上传文件的根节点导入；提供导入目标选择或默认导入到书签栏。                   | 上传导出的 JSON 后，只导入文件中的书签；不会复制当前已有书签树；无效 JSON 有明确提示。  |
| IMP-002 | P0     | Bug 修复   | 修复撤销移动功能不可用                               | 页面有 `undoStack` 和撤销按钮，但移动书签时没有记录 `MoveRecord`，撤销按钮基本不会生效。                                                                    | 移动前读取书签原 `parentId/index`，移动后把记录压入 `undoStack`；批量移动可记录多条或一个批量事务。  | 单个/批量移动后撤销按钮可用；点击撤销能把书签恢复到原文件夹和顺序。                     |
| IMP-003 | P0     | Bug 修复   | 修复批量删除文件夹和书签混合选择                     | `handleDeleteSelected` 使用 `chrome.bookmarks.remove(id)`，如果选中项未来包含文件夹或非空文件夹会失败；当前选择只覆盖书签，但功能边界不清晰。               | 要么限制选择项只允许书签并在 UI 上明确；要么支持文件夹选择并对文件夹使用 `removeTree`。                | 选择项类型行为一致；删除失败不会造成部分状态异常；提示中说明删除对象类型。              |
| IMP-004 | P1     | 稳定性     | 统一 Chrome Bookmarks API 的 Promise/Callback 写法   | 项目中既有 `await chrome.bookmarks.*`，也有 callback 风格；错误处理不统一，部分 API 失败只 `console.error`。                                                | 在 `src/lib/bookmarks.ts` 封装 create/update/remove/removeTree/getTree/move 等方法，组件只调用封装层。 | 组件中不直接调用 `chrome.bookmarks`；常见失败路径都有 toast 提示；mock 环境仍可运行。 |
| IMP-005 | P1     | 构建质量   | 移除构建脚本对外部 `Smart-Bookmark` 目录的依赖     | `scripts/copy-assets.cjs` 会尝试从相邻项目 `Smart-Bookmark/dist/icons` 复制图标，项目可移植性弱。                                                           | 把图标作为本项目资产管理；构建时只复制本项目内资源；避免生成疑似无效 PNG fallback。                      | 新环境 clone 后无需相邻目录即可构建出完整扩展资源。                                     |
| IMP-006 | P1     | 可维护性   | 拆分过大的 `App.tsx`                               | `src/App.tsx` 同时包含状态管理、书签树算法、导入导出、拖拽、UI 渲染，文件接近 800 行。                                                                        | 提取 hooks：`useBookmarks`、`useColumns`、`useSelection`、`useImportExport`；纯函数移到 lib。    | `App.tsx` 只负责页面组合和事件串联；核心逻辑有独立函数可测试。                        |
| IMP-007 | P1     | 类型安全   | 去掉 `promptModal.data?: any` 和导入节点 `any[]` | 当前 modal 状态和导入树缺少类型约束，容易引入运行时错误。                                                                                                       | 使用 discriminated union 定义 prompt modal；为导入 JSON 定义 `ImportedBookmarkNode` 并做运行时校验。   | TypeScript 能根据 modal 类型推断 data 字段；导入未知结构时显示错误而不是静默失败。      |
| IMP-008 | P1     | 数据持久化 | 使用 `chrome.storage` 保存扩展设置                 | manifest 申请了 `storage` 权限，但主题、语言、列布局目前使用 `localStorage`。扩展环境下 `chrome.storage.local` 更适合跨页面/扩展上下文。                  | 将 locale/theme/columns 状态迁移到 `chrome.storage.local`，保留本地开发 fallback。                     | 扩展重新打开后设置稳定恢复；多个扩展页面间状态一致。                                    |
| IMP-009 | P1     | 交互体验   | 用自定义确认弹窗替代多次 `confirm()`               | 删除非空文件夹时连续三次浏览器确认框，体验生硬且不可国际化/不可样式化。                                                                                         | 做统一 ConfirmModal，支持危险操作二次确认、输入文件夹名确认等。                                          | 删除危险操作有清晰说明；不会出现连续系统弹窗；键盘和取消行为一致。                      |
|         |        |            |                                                      |                                                                                                                                                                 |                                                                                                          |                                                                                         |
| IMP-011 | P1     | 用户反馈   | 完善失败提示和加载状态                               | 移动失败、创建失败、更新失败等路径多为 `console.error`，用户不知道操作是否失败。                                                                              | 所有异步操作增加 pending/disabled 状态和失败 toast；必要时提供重试。                                     | 断权、无效书签 ID、导入失败等场景都有用户可见反馈。                                     |
| IMP-012 | P2     | 性能       | 优化大书签库渲染                                     | 当前递归渲染所有展开节点，超大书签库时可能卡顿。                                                                                                                | 对列内列表做虚拟滚动；搜索/过滤时 debounce；避免频繁全量 `loadBookmarks()`。                           | 数千书签场景滚动和展开仍流畅；移动/重命名只刷新受影响列。                               |
| IMP-013 | P2     | 工程质量   | 添加测试与静态检查脚本                               | package 只有 build/preview，没有 lint/test。                                                                                                                    | 引入 ESLint、Prettier、Vitest/React Testing Library；为书签树纯函数和导入导出逻辑写单测。                | `npm test`、`npm run lint` 可运行；核心纯函数覆盖关键边界。                         |
| IMP-014 | P2     | 发布质量   | 补充 README 和安装/打包说明                          | 仓库根目录没有项目 README，扩展加载和构建步骤不明显。                                                                                                           | 编写 README：功能介绍、开发启动、构建、Chrome/Edge 加载 unpacked extension、已知限制。                   | 新用户按 README 可完成本地构建和浏览器加载。                                            |
| IMP-015 | P2     | UI 细节    | 改进空文件夹清理弹窗的选择语义                       | 当前文案是“选择要保留，未勾选删除”，但 checkbox 选中通常表示要操作，容易误删。                                                                                | 改为“选择要删除”的正向语义，或提供全选删除/全选保留按钮和更明显的删除数量预览。                        | 用户能直观看出哪些文件夹将被删除；默认不误删。                                          |

## 可新增功能任务

| ID       | 优先级 | 类型     | 功能                        | 用户价值                                                   | 建议方案                                                                     | 验收标准                                                           |
| -------- | ------ | -------- | --------------------------- | ---------------------------------------------------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| FEAT-001 | P1     | 搜索     | 全局书签搜索与列内过滤      | 快速定位大量书签，减少手动展开目录。                       | 顶部增加搜索框；支持按标题/URL/路径搜索；结果可跳转到所在文件夹。            | 输入关键词后能看到匹配书签和路径；点击结果打开或定位。             |
|          |        |          |                             |                                                            |                                                                              |                                                                    |
| FEAT-003 | P1     | 编辑     | 同时编辑书签标题和 URL      | 当前重命名书签只更新 title，不能修改 URL。                 | 将重命名弹窗扩展为编辑书签表单，包含 title/url。                             | 编辑后标题和 URL 都更新；无效 URL 不提交。                         |
| FEAT-004 | P1     | 组织整理 | 查找重复书签                | 书签管理常见需求，可帮助清理重复 URL。                     | 扫描全量树，按标准化 URL 分组；展示重复项路径；支持选择删除或移动。          | 能列出重复 URL；用户可选择保留一个并删除其余。                     |
| FEAT-005 | P1     | 组织整理 | 查找失效书签                | 帮助清理 404/无法访问链接。                                | 后台批量请求需注意权限和速率；先实现手动检测选中/当前文件夹，展示状态。      | 能检测当前文件夹链接可访问性；不会一次性高频请求大量站点。         |
| FEAT-006 | P2     | 拖拽增强 | 支持拖到具体位置排序        | 当前拖到列时移动到固定位置，不能精确排序。                 | 在书签项之间显示 drop indicator；移动时传入目标 index。                      | 拖动后书签出现在用户放置的位置。                                   |
| FEAT-007 | P2     | 批量操作 | 批量移动到指定文件夹        | 现在批量移动依赖拖到列，不适合目标文件夹不在当前列时使用。 | 增加“移动到…”按钮，弹出文件夹选择器。                                     | 选中多个书签后可搜索目标文件夹并批量移动。                         |
| FEAT-008 | P2     | 视图     | 书签详情侧栏/预览           | 展示 URL、创建时间、所在路径，便于整理。                   | 点击书签时显示详情面板；支持复制 URL、打开、编辑。                           | 用户不打开链接也能查看和复制详细信息。                             |
| FEAT-009 | P2     | 个性化   | 可保存多套列布局            | 用户可能需要工作/个人/临时整理等不同布局。                 | 保存 columns 配置为 layout presets；支持命名、切换、删除。                   | 可以保存当前列布局并在之后一键恢复。                               |
| FEAT-010 | P2     | 导入导出 | 支持标准 HTML 书签导入/导出 | 浏览器书签通用格式是 Netscape HTML，JSON 互通性较弱。      | 增加 HTML parser/exporter；保留 JSON 作为备份格式。                          | Chrome/Edge 导出的 HTML 可导入；本扩展导出的 HTML 可被浏览器导入。 |
|          |        |          |                             |                                                            |                                                                              |                                                                    |
| FEAT-012 | P2     | 安全操作 | 回收站/软删除               | 删除书签风险高，尤其是批量和文件夹删除。                   | 删除前把节点 JSON 备份到 `chrome.storage.local` 的近期删除列表，支持恢复。 | 删除后可在近期删除中恢复；超过限制再清理旧记录。                   |
| FEAT-013 | P2     | 国际化   | 更多语言与自动跟随系统语言  | 当前只有中英文。                                           | 抽象 locale registry；新增语言包；支持“跟随系统”。                         | 设置中可选择语言；默认可跟随浏览器语言。                           |
|          |        |          |                             |                                                            |                                                                              |                                                                    |
| FEAT-015 | P2     | 统计     | 书签统计面板                | 让用户了解书签总量、空文件夹、重复链接、域名分布。         | 顶部或侧栏展示统计卡片；点击统计项跳转到清理工具。                           | 能显示总书签数、文件夹数、重复数、空文件夹数。                     |
